# ✅ Todo List App

A beautiful and functional todo list application built with React, Vite, and Tailwind CSS. This project helps users manage their daily tasks with an intuitive interface and local storage persistence.

## ✨ Features

- **Add Tasks**: Quickly add new todos with a simple input form
- **Complete Tasks**: Mark tasks as completed with a checkbox
- **Delete Tasks**: Remove tasks you no longer need
- **Task Counter**: See total tasks and completed tasks at a glance
- **Local Storage**: Your tasks are saved automatically in your browser
- **Responsive Design**: Works perfectly on mobile, tablet, and desktop
- **Beautiful UI**: Gradient background and smooth hover effects

## 🛠️ Technologies Used

- **React 18** - UI library
- **Vite** - Build tool and development server
- **Tailwind CSS** - Styling
- **Local Storage API** - Data persistence
- **Git & GitHub** - Version control
